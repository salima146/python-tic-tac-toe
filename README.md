# Tic Tac To Game ⭕

## Overview
This is a two-player Tic Tac To game built in Python. Two players take turns using the same mouse to select positions on the board. The game focuses on core logic such as turn handling, win detection, and draw conditions.

## Features
- Two-player local gameplay (shared device)
- Mouse-based input system
- Turn-based mechanics
- Win detection (rows, columns, diagonals)
- Draw detection
- Simple and clean interface

## Technologies Used
- Python

## How to Run

1. Make sure Python is installed.

2. Run the game using:
```
python tic tac to.py
```

3. Use the mouse to click on the grid and play turns alternately.

## Skills Demonstrated
- Python programming
- Event handling (mouse input)
- Game logic design
- Condition-based decision-making
- State management
